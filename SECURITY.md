# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to **fazalabbas2002@gmail.com** rather than opening a public issue.

Include:

- what you found and where (URL or file and line)
- steps to reproduce
- the impact you think it has

You should get a reply within 5 days. Please give a reasonable amount of time for a fix before disclosing anything publicly.

## Scope

In scope: the code in this repository and the live demo at https://retro-records.vercel.app.

Please don't run automated scanners or load tests against the live demo, don't access other users' data, and don't try to break the hosting provider or database provider themselves.

## Supported versions

Only the latest commit on `main` is supported.
